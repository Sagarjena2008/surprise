SHREYANSHI (BHUMI) BIRTHDAY WEBSITE

FILES
- index.html: welcome homepage (GitHub Pages needs this at repository root)
- wishes.html: birthday wishes
- memories.html: photo gallery
- style.css: website design
- assets/: all 8 photos used by the website

IMPORTANT GITHUB PAGES STEPS
1. Extract this ZIP on your computer.
2. Open your GitHub repository.
3. Upload the FILES inside this folder, not the ZIP itself and not the enclosing folder.
4. Make sure index.html and style.css are visible at the top/root level of the repository, and assets is a folder at that same level.
5. Commit changes.
6. Open repository Settings > Pages. Choose Deploy from a branch, branch main, folder /(root), then Save.
7. Wait a minute or two and open https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/ . Replace the placeholders with your GitHub username and repository name.

PHOTO FIX
The gallery now uses simple local paths such as assets/photo-01.jpg. Do not rename the photos or move assets elsewhere. GitHub filenames are case-sensitive.
